# Rice2k Magic Tasks Hotkeys

## Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl+K` | Quick add a task. |
| `Ctrl+T` | Open Tasks. |
| `Ctrl+D` | Open Dashboard. |
| `Ctrl+M` | Open Calendar. |
| `F1` | Open Help. |
| `Enter` in the add-task box | Add the typed task. |
| `Enter` in small popups | Confirm the typed value when supported. |

## Mouse Actions

| Action | Result |
| --- | --- |
| Click a task card | Select the task. |
| Drag a task card | Reorder it inside the list. |
| Double-click a task card | Edit the task. |
| Right-click a task card | Open the full task menu. |
| Click **Steps** | Break the selected task into subtasks. |
| Click **More** | Open the full task menu. |
| Double-click a calendar day | Add an event. |
| Right-click a calendar day | Add an event, add a task due that day, or jump to today. |
| Double-click a calendar event | Edit the event. |
| Right-click a calendar event | Edit, duplicate, repeat, convert to task, or delete. |
| Drag a calendar task or event | Move it to another day. |

## Helpful Navigation

| Place | Fastest Way |
| --- | --- |
| Add a new task | `Ctrl+K` or the task add box. |
| Change task list | Click a task-list tab. |
| Reorder tasks | Drag a task card up or down. |
| Schedule a task | Right-click task, then choose **Schedule**. |
| Change repeats | Right-click task, then choose **Repeats**. |
| Jump calendar months | Use the month and year pickers. |
| Change appearance | Open **Settings**. |
