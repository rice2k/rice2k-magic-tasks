# Rice2k Magic Tasks v2.2.0

Initial public release.

## Highlights

- Windows desktop task manager with local JSON storage.
- Smart task rewriting and automatic breakdowns.
- Multiple task lists with nested subtasks.
- Due dates, times, reminders, and recurring tasks.
- Dashboard, monthly calendar, templates, and ADHD-friendly focus mode.
- Right-click task menu for edit, duplicate, rewrite, breakdown, focus, complete, and delete.
- Immediate theme preview in Settings before saving.
- Seven themes, including Low Stimulation, Focus Contrast, Soft Pastel, and Black & Green.
- Optional Windows system tray integration when packaged with the release dependencies.

## Notes

The app stores data locally in `%APPDATA%\Rice2kMagicTasks\tasks.json`.
The Windows executable is unsigned, so Windows may show a SmartScreen warning on first launch.
