# Rice2k Magic Tasks User Guide

This guide explains the main flow without needing to read the source code.

## Install

1. Download the latest EXE from the [Releases](https://github.com/rice2k/rice2k-magic-tasks/releases) page.
2. Open the EXE.
3. If Windows SmartScreen appears, choose the option to run it anyway only if you downloaded it from this repository.

## Add Your First Task

1. Open the **Tasks** tab.
2. Pick a task-list tab, such as `Today`, `Home`, or `Work`.
3. Type a task into **What do you want to get done?**.
4. Press **Add Task** or press `Enter`.

The app rewrites the task into clearer action wording and adds helpful notes.

## Use Options Only When Needed

The main task page stays simple by hiding extra fields behind **Options**.

Use **Options** when you want to set:

- Detail level for how many steps the planner should create.
- Due date.
- Due time.
- Repeating schedule.
- Templates.

## Work With Task Cards

Each task card has a few main controls:

| Button | Use |
| --- | --- |
| Done | Complete or reopen a task. |
| Steps | Break a task into smaller subtasks. |
| Edit | Change task text, notes, date, time, reminders, or repeat settings. |
| More | Open the full action menu. |

Right-click a task for the same full menu.

You can also drag task cards up or down to reorder them. Subtasks can be dragged within the same parent task.

## Full Task Menu

The task menu includes:

- Complete or reopen.
- Edit task.
- Add note.
- Add subtask.
- Break down into steps.
- Make easier.
- Estimate.
- Schedule.
- Repeats.
- Priority.
- Category.

- Show on calendar.
- Copy Markdown.
- Duplicate.
- Move up or down.

## Use Task Lists

Task lists appear as tabs near the top of the Tasks page.

Use **New List** to create another list.

Use **List Tools** for:

- New list.
- Rename current list.
- Open templates.
- Estimate the current list.
- Prioritize the current list.
- Copy Markdown.
- Save to file.
- Load from file.
- Clear completed tasks.

## Use Calendar

Open **Calendar** to see dated tasks and events.

Calendar actions:

- Use **Previous**, **Today**, and **Next** for nearby months.
- Use the month and year pickers to jump farther.
- Double-click a day to add an event.
- Right-click a day to add an event or task.
- Drag a task or event to another day to reschedule it.
- Double-click an event to edit it.
- Right-click an event to duplicate, repeat, convert to task, or delete it.

## Use Focus Mode

Focus Mode shows one task at a time.

Use it when the task list feels too busy:

1. Open **Focus**.
2. Choose a timer: 5, 15, or 25 minutes.
3. Capture distracting thoughts in the side box.
4. Mark the task complete or move to the next one.

## Use Templates

Open **Templates** to apply built-in task sets or save your own list as a reusable template.

Built-in templates include:

- Morning Reset.
- Weekly Planning.
- Appointment Prep.
- Home Cleanup.
- Work Kickoff.

## Change Themes And Reading Size

Open **Settings**.

Themes preview immediately. Press **Save Settings** to keep the look, or **Cancel** to restore the previous appearance.

Reading controls include:

- Compact text.
- Comfort text.
- Large text.
- Smaller task rows.
- Plain background.

## Data Storage

Your app data is stored locally:

```text
%APPDATA%\Rice2kMagicTasks\tasks.json
```

Back up that file if you want a manual copy of your tasks.
